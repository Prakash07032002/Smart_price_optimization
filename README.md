# 📊 Smart Price Recommendation System

## 🔍 Overview

The Smart Price Recommendation System is a data-driven application that helps users make better purchasing decisions by predicting future product prices and providing buying recommendations.

---

## 🚀 Features

* 📈 Price Prediction using LSTM (Deep Learning)
* 💰 Budget-Based Product Recommendation
* 📊 Interactive Forecast Charts (Plotly)
* 📅 Best Time to Buy Analysis
* 🎯 User-Friendly Dashboard using Gradio

---

## 🧠 How It Works

1. User selects category and product
2. Historical price data is processed
3. LSTM model predicts future prices
4. System analyzes trends
5. Recommendation is generated (Buy Now / Wait)

---

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* TensorFlow / Keras (LSTM)
* Plotly
* Gradio

---

## 📌 Use Case

This system helps users:

* Save money by buying at the right time
* Understand price trends
* Make data-driven purchase decisions

---

## 📷 Output

* Predicted Price
* Recommendation (Buy Now / Wait)
* Price Forecast Graph
